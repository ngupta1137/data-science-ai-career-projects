# Decision memo: which drift monitor to run weekly

Generated by `python -m drift_monitor.report` from `results/`. Do not edit by hand.

## The question
Can a team run a label-free drift monitor with a calibrated threshold and trust that it rarely cries wolf and catches a real shift?

## The rule, set before results were seen
Pass only if both hold for the headline label-free monitor on fresh test streams: (1) the stream-level false alarm rate on null streams has a 95% interval whose upper bound is at most 0.10, which is twice the 0.05 budget the threshold was calibrated to; (2) the detection rate for the abrupt covariate shift has a 95% interval whose lower bound is at least 0.80. Both limits are design choices made before results were seen.

## The call: FAIL
Headline monitor psi_max.
- false_alarm_within_limit: False
- abrupt_shift_detected: True

Stream-level false alarm rate on the test null streams: 0.070 (0.046 to 0.105). Abrupt covariate shift detection: 1.000 (0.987 to 1.000).

## What the gate result does and does not say
The follow-up on 2000 fresh null streams (post hoc, not part of the gate) gives 0.062 (0.053 to 0.074) for the headline against a target of 0.05. The monitor failed on the pre-set limit. A likely reason is calibration noise: thresholds set from 1000 null streams leave the achieved false alarm rate off target by more than the gate allows for, and this project did not test that cause. Calibration needs many null streams, and a real team has one reference history, not a thousand simulated years.

## What a wrong call costs
Too many false alarms and the team stops reading the alert. A missed shift means a model degrades unseen. Fixed PSI cutoffs fail both ways: at batch size 100, PSI > 0.2 raised a false alarm in 1.000 (0.987 to 1.000) of null streams, and at batch size 500 it missed small shifts the calibrated monitor caught.

## Where not to trust it
Concept drift. The headline detects it in 0.033 (0.018 to 0.060) of streams because the inputs do not move. Only the label-based monitor sees it, after a delay of 4 weeks here. A label-free monitor alone is not a performance monitor.

## Not done
No calibration by resampling real reference weeks. No retraining or adaptive reference. No seasonality. No text or image inputs. No real production data.
