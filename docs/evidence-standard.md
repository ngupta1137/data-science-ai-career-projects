# Evidence standard

A project in this repository is not finished because a notebook runs. It is
finished when a stranger can reproduce every reported number and can see where
the model fails.

## Required in every project

| Item | Where | Test of done |
|---|---|---|
| Problem framing and decision context | `README.md` | States who acts on the prediction and what a wrong prediction costs |
| Data card | `data/DATA_CARD.md` | Source, license or terms, known quirks, what was not checked |
| Reproducible data access | `src/` | Script downloads data and verifies a checksum. Third-party data is never committed |
| Baseline | `src/` | A dumb model reported first, so gains are measured against something |
| Split design | `src/` | Split matches how the model will be used, with the leakage risk named |
| Tests | `tests/` | Data validation, leakage, metric unit tests against hand-computed values |
| Committed metrics | `results/metrics.json` | Written by code, never typed. Includes seed and library versions |
| Uncertainty | `results/metrics.json` | Confidence intervals on the headline metric |
| Error analysis | `results/error_analysis.json` | Errors by segment, with the worst segment named |
| Model card | `reports/model_card.md` | Rendered from the metrics, states limits and intended use |
| Decision memo | `reports/decision_memo.md` | One page, rendered from the metrics, states the call and the risk |

## Rules

1. **No typed numbers.** Any metric in a report comes from `results/`. Reports are rendered by code.
2. **Label status.** Every claim is built, designed, or proposed. A project's `STATUS` file holds `planned`, `in_progress`, `built` (results generated and committed), or `released` (archived on Zenodo).
3. **Seeds fixed, versions recorded.** Metrics files record the seed and library versions.
4. **Show the trap.** Each project demonstrates one failure that beginners hit (leakage, wrong split, wrong metric) and shows the size of the damage.
5. **State what was not done.** Each README lists what the project deliberately leaves out.
6. **Plain language.** No em dashes. No filler.

## Metrics file schema (all projects)

```json
{
  "project": "01-house-price-regression",
  "seed": 42,
  "versions": {"python": "...", "numpy": "...", "pandas": "...", "scikit-learn": "..."},
  "data": {"rows": 0, "sha256": "..."},
  "split": {"strategy": "...", "train": 0, "test": 0},
  "models": {"<name>": {"<metric>": 0.0}},
  "headline": {"model": "...", "metric": "...", "value": 0.0, "ci95": [0.0, 0.0]}
}
```

Values above are shape only. Real files are generated by `src/train.py`.
