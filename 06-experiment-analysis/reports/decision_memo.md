## The question
Can a team adopt CUPED with a fixed horizon and Holm correction as its default analysis, and trust the false positive rate and the interval?

## The rule, set before results were seen
Pass only if all four hold, each judged on 95% intervals from the simulation: (1) at the headline cell, the A/A false positive rate of CUPED with a fixed horizon has an interval that contains 0.05; (2) at the headline cell with a true effect, the CUPED estimate has no detectable bias (the interval on the mean error contains 0); (3) the variance of the CUPED estimate divided by the variance of the raw estimate has an interval whose upper bound is below 1; (4) the Holm family-wise error rate over the multiple-metric A/A set has an interval whose lower bound is at or below 0.05.

## The call: PASS
- aa_false_positive_contains_nominal: True
- cuped_unbiased: True
- cuped_variance_ratio_below_one: True
- holm_family_wise_error_controlled: True

CUPED cut the variance to 0.653 of the raw estimate (0.620 to 0.685), which cuts the users needed by 36.0% at correlation 0.6.

## What a wrong analysis costs
Peeking at 10 looks gives a false positive rate of 0.194, about 3.9 times the nominal 0.05. Each false positive ships a change that does nothing. A covariate that moves with treatment turns CUPED into a machine that removes real effect: mean error -0.287 against a true effect of 0.1.

## Where not to trust it
Small samples. The grid flags cells where the false positive rate or interval coverage is off. A likely cause for CUPED is that the standard error ignores the estimated coefficient, but this project does not test that. Heavy tails with few users are another risk. See the flagged cells in the model card.
