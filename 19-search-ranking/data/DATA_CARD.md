# Data card: Search Ranking and Position Bias Correction

## Source
Simulated search impressions and click logs with known true relevance ground truth. Generated in memory by `search_ranking.data.generate_ranking_data`.
- Deterministic simulation seed: 42 (training: 3,000 queries; holdout test: 1,000 queries; 10 candidate items per query).
- Cryptographic SHA-256 fingerprint pinned in `data/CHECKSUMS.txt`.

## Terms
Self-contained synthetic dataset generated by open-source code under the repository license (CC-BY-4.0).

**Data storage best practice:** Following industry best practices for algorithmic evaluation, raw synthetic CSV artifacts are not committed to git to prevent repository bloat and maintain clean version control. The dataset is generated on the fly via `python -m search_ranking.train`.

## Shape
Documented by the simulation:
- 3,000 training search queries (30,000 impressions; 2,204 clicks).
- 1,000 holdout test queries (10,000 impressions; 703 clicks).
- 10 candidate items per query impression.
- Query segments: Head (25%), Torso (45%), Tail (30%).

| Field | Meaning |
|---|---|
| query_id | Unique integer search query session identifier |
| query_type | Stratified query frequency category (head, torso, tail) |
| doc_id | Candidate document identifier within query (0 to 9) |
| pos | 1-indexed presentation rank in logged session (1 to 10) |
| exam_prob | True position examination probability: P(examine \| pos) = 1 / (pos ** 1.35) |
| true_rel | True latent graded relevance (0: irrelevant, 1: marginal, 2: relevant, 3: highly relevant) |
| semantic | Deep semantic text match signal (true relevance with Gaussian noise) |
| bm25 | Standard lexical BM25 matching score |
| quality | Merchant/product quality and seller rating score |
| pop_bias | Historical popularity and catalog exposure confounder |
| prod_score | Baseline production ranker score: 0.65 * bm25 + 0.35 * quality |
| log_score | Historical logging policy score with rank exploration perturbation |
| click | Observed binary user click indicator (1 if clicked, 0 otherwise) |

## Known quirks
- **Cascade position bias:** User examination probability decays sharply with position (position 1 receives ~44% of total clicks, while position 10 receives <1%).
- **Popularity distortion:** Historical popularity is an exposure confounder. On head queries, popularity is mildly correlated with relevance, but on tail queries, popular items act as irrelevant distractors.
- **Single-click simplification:** User clicks follow an independent examination and attraction model without post-click satisfaction abandonments or query reformulation.

## Not checked
- Session-level multi-query reformulations or search filter refinements.
- Personalized user historical preferences or cross-session intent tracking.
- Dynamic carousel and rich media visual snippet eye-tracking heatmaps.
