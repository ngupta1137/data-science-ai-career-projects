# Model Card: Search Ranking and Position Bias Correction

**Project:** `19-search-ranking`
**Domain:** E-commerce, Media and Consumer Apps
**Decision Gate Status:** **PASSED** (reported as is)

## Model Overview
- **Headline Architecture:** Inverse Propensity Scoring (IPS) point-wise ranker with clipped examination propensity weights.
- **Decision Purpose:** Determine whether to ship the candidate ranker to replace the production BM25 lexical ranking policy.
- **Headline Metric:** True Unbiased NDCG@10 lift over production baseline on holdout search queries.
- **Headline Result:** True NDCG@10 lift = +0.0425 (95% CI: [+0.0383, +0.0459]).

## The Traps, Measured
- **Trap 1: Position bias decay in logged clicks**: Clicks are overwhelmingly concentrated at top positions due to examination bias, with the top 3 positions capturing the vast majority of clicks.
  - Top 3 positions capture 85.6% of all clicks.
  - Bottom 4 positions capture only 5.4% of clicks.
  - Top-to-bottom click concentration ratio: 15.8x.
- **Trap 2: Offline gain that vanishes once position bias is removed**: Naive rankers trained on raw clicks appear competitive on biased click metrics, but their apparent offline gain vanishes or reverses on true relevance.
  - Naive ranker apparent biased click lift: +0.0001.
  - Naive ranker true unbiased relevance lift: -0.0024.
  - IPS ranker true unbiased relevance lift: +0.0425.
- **Trap 3: Tail query degradation masked by head queries**: Historical popularity features cause naive rankers to degrade tail and niche queries by promoting irrelevant brand distractors, while IPS debiasing preserves tail relevance.
  - Naive head query lift: +0.0062.
  - Naive tail query lift: -0.0223 (catastrophic degradation).
  - IPS debiased tail query lift: +0.0255.

## Operational Limits and Caveats
- Impressions and clicks are generated by a simulated cascade position-examination model.
- Real search users display multi-click sessions, query reformulation, and satisfaction abandonments.
- Position bias eta is assumed known; production deployments estimate propensities via randomization or dual learning.
- Relevance grades reflect static document utility rather than dynamic personalized intent.
