## How the mapping was made

A project is marked main for a domain when its core skill is a routine task in that domain. It is marked also when the skill applies but is not the usual first need. This is a judgement, not a measurement, and it is open to challenge in an issue. No project uses real data from any domain, so a mapping tells you which skill to practise, not that the result transfers.
