# Data card: Multi-Touch Attribution

## Source
Simulated customer conversion journeys with known true counterfactual incrementality. Generated in memory by `touch_attribution.data.generate_journeys`.
- Deterministic simulation seed: 42 (training: 40,000 journeys; holdout test: 10,000 journeys).
- Cryptographic SHA-256 fingerprint pinned in `data/CHECKSUMS.txt`.

## Terms
Self-contained synthetic dataset generated by open-source code under the repository license (CC-BY-4.0).

**Data storage best practice:** Following industry best practices for algorithmic evaluation, raw synthetic CSV artifacts are not committed to git to prevent repository bloat and maintain clean version control. The dataset is generated on the fly via `python -m touch_attribution.train`.

## Shape
Documented by the simulation:
- 40,000 training customer journeys; 10,000 holdout test journeys.
- 4 marketing channels: Display, Social, Paid Search, Email.
- Journey touchpoint sequence length: 1 to 5 touches per user.

| Field | Meaning |
|---|---|
| user_id | Unique integer customer journey identifier |
| path | Sequential list of marketing channels touched before conversion decision |
| converted | Binary indicator (1 if the user converted, 0 if dropped off) |
| conversion_prob | True underlying conversion probability given active touchpoints |
| organic_prob | Baseline probability of conversion if all ad touchpoints were removed |
| true_channel_lifts | Dictionary of true causal counterfactual lifts for each channel |

## Known quirks
- **First-order Markov transitions:** User movement between marketing touchpoints follows stationary first-order transition probabilities without higher-order memory of earlier channels.
- **Organic baseline conversion:** Approximately 36% of converting customers would have converted even if all marketing touches were removed, establishing that not all conversions are incremental.
- **Channel synergy:** Display awareness and Social engagement amplify the conversion lift of bottom-of-funnel Paid Search.
- **Static channel touch costs:** Channels have fixed unit touch costs ($0.50 Display, $1.20 Social, $2.50 Search, $0.15 Email) without competitive real-time auction bidding dynamics.

## Not checked
- Cross-device identity linkage loss, private browsing, and ad-blocker suppression.
- Long-term multi-quarter brand equity buildup past the immediate multi-week purchase cycle.
- Creative variation, message fatigue, and frequency capping effects.
